== Contexte général

Ce dépôt contient l’ensemble du suivi de projet réalisé dans le cadre de la SAÉ 5.01.
Il regroupe nos livrables, backlogs, comptes-rendus et contributions au projet open source *StreetComplete*.

StreetComplete est une application Android qui permet d’améliorer facilement les données d’*OpenStreetMap* (OSM). 
OSM est une carte mondiale collaborative où chacun peut ajouter ou corriger des informations (routes, bâtiments, commerces, équipements publics, etc.). 

StreetComplete simplifie cette contribution en proposant des *“quêtes”* géolocalisées : de petites questions permettant de compléter ou vérifier des données manquantes sur le terrain. 
L’application mise sur une approche *ludique* et *accessible* pour encourager la participation, même sans connaissance préalable d’OSM.
